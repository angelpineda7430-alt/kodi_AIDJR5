# Analizador de Logs en Python

## Descripcion
Programa desarrollado en Python para analizar archivos de texto que simulan registros de eventos de una aplicacion.

## Funcionalidades
- Lectura de archivos TXT.
- Identificacion de niveles INFO, WARNING y ERROR.
- Validacion de fechas.
- Deteccion de registros incompletos o malformados.
- Generacion de resumen estadistico en consola.

## Requisitos
Python 3.9 o superior.

## Ejecucion
python analizador_logs.py

Tambien se puede indicar el archivo directamente:

python analizador_logs.py prueba_correcta.txt

python analizador_logs.py prueba_inconsistente.txt

## Archivos de prueba
- prueba_correcta.txt
- prueba_inconsistente.txt
