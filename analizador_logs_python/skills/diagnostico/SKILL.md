# Skill: Diagnóstico de logs

## Cuándo utilizarla
Cuando el usuario solicite explicar errores, identificar problemas, priorizar hallazgos o conocer posibles causas.

## Instrucciones
1. Prioriza los eventos clasificados como ERROR.
2. Señala por separado los eventos WARNING y las líneas malformadas.
3. Usa el número de línea y el texto original como evidencia.
4. Distingue hechos observados de hipótesis.
5. No afirmes una causa raíz si el log no contiene evidencia suficiente.
6. Sugiere verificaciones concretas y prudentes.
