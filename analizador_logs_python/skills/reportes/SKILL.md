# Skill: Reportes técnicos

## Cuándo utilizarla
Cuando el usuario solicite un informe, reporte o documento de resultados.

## Instrucciones
1. Incluye el nombre del archivo y las métricas calculadas por Python.
2. Resume los hallazgos por nivel de severidad.
3. Incluye incidencias con número de línea y motivo.
4. No ocultes registros malformados.
5. No agregues cifras ni conclusiones que no estén sustentadas por el análisis.
