# Skill: Análisis de logs

## Cuándo utilizarla
Cuando el usuario solicite un resumen, conteos, estadísticas o métricas del archivo analizado.

## Instrucciones
1. Utiliza los eventos estructurados producidos por el analizador Python.
2. Informa el total de eventos y los conteos INFO, WARNING, ERROR y SIN_CLASIFICAR.
3. Informa fechas válidas y líneas malformadas.
4. No calcules cifras manualmente ni inventes resultados.
5. Aclara que las líneas vacías se ignoran.
